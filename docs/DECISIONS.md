# Решения и оставшиеся вопросы

## Ответы владельца

- Ручная зашифрованная копия на компьютер/USB, облако не нужно.
- Vivo X200 Pro mini, нужна поддержка большинства телефонов от 2020 года.
- Отпечаток или **отдельный PIN приложения**, не системный код.
- Только личное использование на первом этапе; Autofill позже.
- Покупки — каталог вещей: фото/описание/ссылка/оценка эксплуатации 1–10.
- Семь основных категорий и исходно указанные кафе/рестораны.
- Выбрана «Бумага» — белый и графитовый. Главная становится дашбордом, категории открываются через выдвижное меню слева; нижние вкладки убраны.
- Утверждена компоновка **«Фокус»**: ближайшее дело выделено, остальные блоки ниже. Выбор вариантов завершён.
- Основной агент — Gemini 3.8 Flash; резервный — GPT‑6.1 Sol. Один план и одинаковые критерии для обоих, отдельные рабочие профили в harness/.
- 16.10.2026: владелец явно разрешил начало реализации для диапазона H01–H02 (`implementation-start` approved, `approvedPhases: ["H01", "H02"]`). Запуск переносится в новый чат проекта.

## Нужны до соответствующего этапа

1. Дизайн уже согласован: «Бумага / Фокус». Повторный выбор не нужен; конструктор с перетаскиванием плиток не входит в MVP.
2. Длина PIN согласована (6 цифр, не больше). Для резервной копии сохраняется отдельная длинная парольная фраза.
3. Точная версия Android/оболочки Vivo и возможность тестового APK на устройстве (до этапа 1). Год выпуска не заменяет эти сведения.
4. Ссылка товара только сохраняется или разрешено явное открытие внешнего браузера (до этапа 4). По умолчанию — хранение текста. Внешний браузер может обращаться в интернет и передаёт URL наружу.
5. Насколько важна точность напоминания до минуты и какие повторы нужны (до этапа 6). По умолчанию — разовое/ежедневное/еженедельное, ограничения ОС видны.
6. Сохранять ли исходное качество фото, нужны ли цена/дата покупки (до этапа 4). По умолчанию фото уменьшаются, цена/дата необязательны.
7. Рабочее имя «Моя жизнь» и applicationId (до первого релиза). Поздняя смена applicationId создаёт другое приложение.

Опрос уже закрыл архитектурно значимые вопросы хранения, входа, состава товаров и аудитории. Остальное не мешает завершить план и макеты, но проверяется перед зависимой реализацией.
