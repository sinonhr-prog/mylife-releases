# Продукт и требования

## Подтверждено владельцем

Дата: 16.10.2026. Рабочее имя — «Моя жизнь».

1. Одно приложение на Android, пока для личного использования.
2. Рабочие данные только на телефоне; без сервера, облака, внешних источников, аналитики и регистрации. Единственное узкое сетевое исключение — проверка и скачивание обновлений из публичного канала GitHub Releases через «Настройки → Обновления».
3. Телефон владельца — Vivo X200 Pro mini; нужна совместимость с большинством телефонов с 2020 года.
4. Вход по отпечатку либо **отдельному PIN приложения**.
5. Ручная зашифрованная копия на компьютер/USB, без облака.
6. Разделы: Покупки, Магазины, Парки, Задачи, Заметки, Напоминания, Пароли. Кафе и рестораны из исходного запроса сохраняются как категории мест.
7. Покупка — карточка товара с фото, описанием, ссылкой на покупку, оценкой опыта эксплуатации от 1 до 10. Это не бухгалтерия и не список продуктов.
8. Выбрана тема «Бумага»: белый и графитовый, компоновка главной **«Фокус»**. Другие подготовленные варианты сохраняются как история выбора.
9. Автозаполнение паролей в другие приложения можно добавить позже.
10. Главная — дашборд: текущие дела, ближайшие напоминания, последние посещённые места и последние добавленные записи.
11. Основная навигация — выдвижное меню слева, открываемое значком ☰. В меню доступны все категории приложения; нижняя навигационная панель не используется.

## Рекомендуемые параметры, пока без отдельного подтверждения

- Android 10/API 29 и новее; arm64-v8a, при необходимости armeabi-v7a, x86_64 для эмулятора. Совместимость нативных библиотек проверить до закрепления ABI.
- PIN приложения: 6 цифр (утверждено владельцем 17.10.2026). Разрешить длинную парольную фразу вместо PIN как альтернативный усиленный режим позднее.
- Сейф блокируется при уходе с экрана; всё приложение — при фоне/выключении экрана. После возврата из системного выбора фото — повторный вход с восстановлением несекретного процесса импорта.
- Резервная копия защищается отдельной длинной парольной фразой, не PIN. Предлагать случайную фразу из 6 слов проверенного списка и подтверждение её сохранения.
- Напоминания: разовые и ежедневные/еженедельные; произвольные сложные повторы позднее.
- Уведомление на заблокированном телефоне: «У вас напоминание», без названия задачи.
- Фото: до 5 на карточку, до 20 МБ входной файл; локальное уменьшение до 2048 px по длинной стороне. Лимиты настраиваются после замера качества.
- Русский язык; в первой версии тема «Бумага». Предыдущие цветовые макеты сохранены как история выбора.

## Сценарии первой версии

### Первый запуск и вход

Создать PIN → повторить → проверить защищённую блокировку устройства → по желанию включить отпечаток → объяснить ручную копию и потерю данных → открыть главную. Настоящие секреты вводятся только после приёмки защищённого хранения. Нет удалённого восстановления PIN.

### Главная

Дашборд из четырёх блоков: текущие дела, ближайшие напоминания, недавно посещённые места и последние добавленные записи. Показать по 2–3 записи с переходом к полному списку; пустой блок предлагает подходящее действие. Текущие дела — незавершённые, сначала просроченные, затем ближайшие со сроком, затем без срока. Напоминания — включённые, по следующему времени сигнала. Посещения — по lastVisitedAt, добавления — по createdAt, без сейфа. Не подменять посещение изменением карточки; пользователь сам отмечает «Посетил» и дату. Геолокация и фоновое слежение не нужны.

Слева сверху кнопка ☰: меню плавно выезжает слева поверх содержимого, фон затемняется. Пункты: Главная, Покупки, Магазины, Парки, Кафе, Рестораны, Задачи, Заметки, Напоминания, Пароли, Настройки; пользовательские категории также добавляются в соответствующую группу. Текущий раздел выделяется. Выбор пункта закрывает меню и открывает раздел. Закрытие: крестик, нажатие вне меню, системный Back; в браузерном макете — Escape. Фокус остаётся в открытом меню, после закрытия возвращается к кнопке. Сниженная анимация учитывается. На узких экранах и при крупном шрифте меню и содержимое прокручиваются независимо. Открытие меню из сейфа завершает сессию сейфа; возвращение требует авторизации.

Нижних вкладок нет. Добавление записи доступно отдельной кнопкой; поиск расположен в верхней панели. Утверждён «Фокус» из design/dashboard.html: первое текущее дело по указанной сортировке выделено графитовой карточкой, остальные дела, напоминания, места и записи ниже. Если дел нет, показать спокойное пустое состояние с добавлением задачи; не подставлять выдуманное дело. Конструктор дашборда и переключение четырёх компоновок в MVP не нужны.

### Покупки

Список/поиск → карточка → название, фото, описание, ссылка, оценка 1–10, личные теги, дата покупки и цена необязательны. Неоценённый товар имеет null, а не 0. Редактирование, избранное, архив, удаление с подтверждением. Ссылку сохранять как текст, не загружать страницу или превью автоматически. Открытие внешнего браузера по умолчанию не включать; отдельно согласовать выход за локальный контур.

### Места

Магазины, парки, кафе и рестораны — предустановленные категории. Поля: название, вручную введённый адрес, комментарий, фото, любимое/хочу посетить/посетил, дата последнего посещения lastVisitedAt (необязательная, задаётся пользователем). Оценка места необязательна. Нет карты, геокодинга, скачивания адресов и геолокации в MVP. Пользователь может добавить свою категорию места. Неизвестная дата посещения не выдумывается: такая запись не входит в блок недавних посещений.

### Задачи, заметки и напоминания

Задача: заголовок, описание, срок, статус, приоритет, связанное напоминание. Заметка: заголовок и обычный текст; чек-лист позже. Напоминание: локальное время, часовой пояс, повтор, включено/выключено, связь с задачей либо самостоятельная запись. Завершение задачи отменяет её активные сигналы; перезапуск и смена часового пояса обрабатываются по правилам в архитектуре.

### Сейф

Повторная проверка PIN/отпечатка → список сервисов → карточка логина. Название, сайт, логин, пароль, секретная заметка. Названия и логины тоже зашифрованы. Генератор случайного пароля, показ по явному действию, копирование с предупреждением о буфере. Ни пароли, ни их названия не появляются в общем поиске/главной. Автозаполнение и TOTP вне MVP.

### Копия и восстановление

Пользователь выбирает создание зашифрованной копии, подтверждает доступ к сейфу, задаёт отдельную фразу и сохраняет файл локально/на USB. Перенос на компьютер вручную. Восстановление проверяет фразу, целостность и формат; импорт на новом телефоне создаёт новые локальные ключи и PIN. В MVP только полное восстановление с предварительным показом объёма замены; объединение архивов позднее.

### Встроенные обновления

Первый распространяемый APK уже содержит экран «Настройки → Обновления». Пользователь может по кнопке проверить наличие новой версии через GitHub Releases (`sinonhr-prog/mylife-releases`), просмотреть описание изменений безопасным текстом, скачать проверенный APK во временный кэш и запустить установку поверх существующей версии с подтверждением Android. Перед установкой проверяются размер, хэш SHA-256 и сертификат подписи APK.

## Не входит в первую версию

iOS, сайт, аккаунты, синхронизация, совместный доступ, AI-функции, карта, банковские интеграции, сканирование чеков/OCR, маркетплейсы, браузерное расширение, автозаполнение, сбор пользовательской аналитики, публичный магазин приложений. Масштабирование означает новые локальные функции и больше записей, а не серверы.

## Критерии пользовательской приёмки

- После включения авиарежима можно создать и найти каждую из семи категорий, закрыть приложение, перезапустить телефон и снова получить данные.
- Изменение товара с фото и оценкой не повреждает другие записи.
- Чужой человек не видит записи до входа; общий вход не раскрывает содержимое сейфа.
- Резервная копия восстанавливается на чистой установке другого устройства без старого Keystore.
- Неверный PIN, повреждённый архив, нехватка места и отмена импорта не уничтожают существующие данные.
- Напоминания проверены на Vivo с погашенным экраном и после перезапуска; ограничения ОС показаны пользователю честно.
- Обновление приложения через экран «Настройки → Обновления» загружает новую версию с GitHub, сверяет подпись и сохраняет существующие зашифрованные данные, настройки и сессии.
