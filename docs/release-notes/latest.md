# v0.1.16 — исправлено создание напоминаний

Тестовое обновление существующего канала local.mylife.debug, Android 10/API29 и новее. Полная приёмка безопасности не завершена; используйте синтетические данные.

## Изменения

- Исправлено закрытие приложения при нажатии «Запланировать напоминание».
- Незавершённая форма использует отдельный черновик; проверка названия выполняется перед сохранением.
- Добавлена проверка открытия формы, отмены, пустого названия и сохранения напоминания.

## Проверка

Локально прошли 43 unit-теста приложения, Compose regression на Android 10/API29 (1 тест), debug-сборка, компиляция instrumentation и lint (0 ошибок, 75 предупреждений). CI дополнительно выполняет unit-тесты и сборку подписанного APK.

## Ограничения

Обновление на Vivo, доставка сигналов при Doze/перезапуске и полная приёмка H10 в этом исправлении не проверялись. Сохраняются ограничения биометрического сценария, архитектурной изоляции, нагрузочных проверок, OEM backup/переноса и профильного криптографического ревью.

Устанавливайте поверх приложения с тем же пакетом и подписью. Не удаляйте приложение ради обновления: удаление уничтожает локальные данные.
