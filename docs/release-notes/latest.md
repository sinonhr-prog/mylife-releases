# v0.1.15 — исправления сейфа и интерфейса

Тестовое обновление существующего канала `local.mylife.debug`. Android10/API29 и новее. До полной приёмки используйте только синтетические данные; выпуск не означает готовность для личных секретов.

## Изменения

- Исправлена сжатая кнопка без читаемой подписи в сейфе: теперь это явное действие «Закрыть сейф».
- Исправлено открытие формы добавления пароля; добавлено подтверждение удаления.
- Улучшены размеры и подписи кнопок, прокрутка форм и отображение крупного шрифта. На служебных страницах убрана кнопка добавления записей.
- Исправлены блокировка при уходе в фон, закрытие хранилищ и защита личных экранов от снимков/превью.
- Архив v1 обрабатывается потоково, без временного незашифрованного ZIP с ключами. Добавлено восстановление файловой операции после программного прерывания.
- Счётчик неверных PIN сохраняется между запусками; очевидные последовательности запрещены для новых PIN. Вход с существующим PIN сохранён.
- Проверка обновлений требует точного совпадения пакета; после выдачи разрешения в Android состояние установки обновляется при возврате.

## Проверено

84 unit-теста, 18 instrumentation-тестов на API29, release lint (0 ошибок), локальная release-сборка. Кнопка сейфа проверена на320dp при масштабе шрифта100%/200%.

## Ограничения

Полная приёмка H10 не завершена. Остаются биометрический сценарий, архитектурная изоляция, общий контроль стиля, нагрузочные проверки, OEM backup/перенос и профильное криптографическое ревью. Программное прерывание в тестах не заменяет проверку обесточивания устройства. Обновление этой версии на Vivo ещё не проверено.

Устанавливайте поверх приложения с тем же пакетом и подписью. Не удаляйте приложение ради обновления: удаление уничтожает локальные данные.
