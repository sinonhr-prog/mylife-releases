# ADR 0001: нативный локальный Android

Статус: выбранная архитектурная рекомендация для плана, 16.10.2026.

Контекст: Android, личное использование, локальные данные, отпечаток и отдельный PIN, переносимая ручная копия.

Решение: Kotlin/Compose, minSdk 29, небольшой модульный монолит; SQLCipher для двух изолированных хранилищ, зашифрованные файлы, Keystore; без INTERNET/backend. UI-разделы первоначально пакетами в app, инфраструктурные границы отдельными core-модулями.

Почему: прямой доступ к платформенным механизмам и меньшая цена интеграции на единственной целевой платформе. Room предоставляет типизированный слой и миграции, шифрование обеспечивает отдельная поддерживаемая интеграция SQLCipher.

Последствия: iOS потребует дополнительной разработки; безопасность собственной PIN-обёртки/архива требует технического прототипа и ревью. 2020 год телефона не гарантирует Android 10. Политики ОС могут ограничить уведомления. Восстановление возможно только с копией и фразой.

Отклонённые на текущем этапе варианты: PWA для сейфа/фоновых сигналов; Flutter/React Native без запроса iOS; облачный backend из-за прямого ограничения пользователя; десятки feature-модулей без текущей необходимости.

Следующий ADR на этапе 1: точные криптобиблиотеки, key envelopes, форматы архива, способы инвалидации и миграции.
