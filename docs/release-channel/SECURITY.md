# Безопасность

Статус: APK пока не выпущен. Наличие этого документа не является заключением о безопасности приложения.

## Канал обновлений

Планируется загрузка только из `sinonhr-prog/mylife-releases` через HTTPS. Перед установкой должны проверяться версия, пакет, совместимость, размер, контрольная сумма и криптографическая подпись APK доверенным сертификатом. Установку подтверждает пользователь через Android.

SHA-256 выявляет повреждение файла; контрольная сумма в том же репозитории сама по себе не защищает от захвата аккаунта. Для проверки подлинности необходим доверенный сертификат подписи. Отпечаток сертификата будет опубликован вместе с первой проверенной сборкой.

Закрытые ключи подписи и токены никогда не включаются в APK или этот репозиторий. Обновлятор не должен получать доступ к записям, вложениям, PIN и ключам хранилища. GitHub/CDN получает технические данные соединения, но содержимое пользовательских записей отправляться не должно.

## Сообщение об уязвимости

Не публикуйте реальные пароли, PIN, базы, архивы, токены, персональные сведения и логи с секретами в Issues. Для обычной ошибки используйте минимальный пример на синтетических данных.

Если обнаружена уязвимость, сначала проверьте наличие кнопки приватного сообщения об уязвимости в разделе Security. Если приватный канал недоступен, создайте только нейтральный запрос о способе приватной связи, без деталей эксплуатации и секретов. Отдельный адрес поддержки пока не опубликован.
