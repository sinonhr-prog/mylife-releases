# Моя жизнь — APK и обновления

Официальный канал распространения Android-приложения «Моя жизнь».

**Статус: подготовка канала. Установочного APK и опубликованных версий пока нет. Встроенный обновлятор запланирован, но ещё не реализован и не проверен.**

Здесь публикуются готовые подписанные APK, описания версий и контрольные суммы. Репозиторий не содержит закрытые исходники, ключи подписи или пользовательские данные.

## Установка после появления первого выпуска

1. Откройте [Releases](https://github.com/sinonhr-prog/mylife-releases/releases) на телефоне.
2. Прочитайте статус и ограничения выбранного выпуска; скачайте `mylife.apk` из его Assets.
3. При необходимости разрешите браузеру установку приложений из этого источника и подтвердите установку Android.

Поддержка Android 10/API 29 и новее является целью проекта. Фактически проверенные устройства, архитектуры и ограничения указываются в каждом выпуске. Не используйте тестовые выпуски для реальных секретов до явного объявления о прохождении соответствующей приёмки.

## Обновления после реализации

Первый распространяемый APK должен уже содержать «Настройки → Обновления». Оттуда можно будет проверить новую версию, скачать APK и запустить системное подтверждение установки. Интернет нужен только для получения обновлений; рабочие записи остаются на телефоне. GitHub и его CDN видят технические данные сетевых запросов, включая IP.

Обновление устанавливается поверх приложения с тем же идентификатором и доверенной подписью. Не удаляйте установленное приложение ради обновления: удаление может уничтожить локальные данные. Совместимость и миграции проверяются для каждого выпуска.
