# places

Магазины, парки, кафе, рестораны и свои категории. Будущий UI-пакет app, не отдельный Gradle-модуль.

ViewModel → публичный интерфейс репозитория; без DAO и ключей в UI. Нет прямых импортов внутренних классов другого feature. Правила app/AGENTS.md применяются. Сценарии, поля и проверки находятся в корневых docs/PRODUCT.md и docs/TESTING.md. Пока исходный код отсутствует.
