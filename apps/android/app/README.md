## Канал подписи текущего Vivo — 17.10.2026

Для обновления существующего тестового приложения CI собирает release-вариант с `-PreleaseApplicationIdSuffix=.debug`, итоговый package — `local.mylife.debug`. Это не production-идентичность `local.mylife`; смена package не является обновлением старой установки. Release-вариант сохраняет `debuggable=false`.

Keystore задаётся только через `KEYSTORE_PATH` (абсолютный путь или путь от корня Gradle), остальные параметры — `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`, без стандартных значений по умолчанию. CI декодирует `KEYSTORE_BASE64` в RUNNER_TEMP с ограниченными правами, удаляет файл при выходе шага и проверяет готовый APK через apksigner до подготовки assets. Не изменять проверку сертификата обновлятора для принятия другого ключа.

Проверка наличия четырёх имён secrets в GitHub не подтверждает их значения. Пароль хранилища и пароль приватного ключа должны соответствовать самим байтам keystore: изменение GitHub secret не изменяет keystore. Production-ключ, выпуск и установка на телефон имеют отдельные контрольные точки. SIGN-002 устранён по новому поручению владельца: создан совместимый JKS с исходным debug-сертификатом и желаемыми паролями/alias. Подписанный локальный candidate 20 / 0.1.20 проверен; новый Base64 ещё нужно перенести в GitHub. Проверка на устройстве и публикация не выполнены.
