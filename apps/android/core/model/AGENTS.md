# core/model

Ответственность: Чистые типы, идентификаторы, ошибки и интерфейсы репозиториев.

Допустимые зависимости: Только Kotlin; без Android, Room и Compose.

Проверять инварианты рейтингов/дат/денег и совместимость контрактов; не добавлять DTO хранения.

Данные и совместимость: следовать [DATA_MODEL.md](../../../../docs/DATA_MODEL.md); изменения схемы/контракта сопровождаются миграцией и проверкой совместимости. Не менять чужие хранилища через внутренние классы.

Команды и статус — в README.md этого модуля и родительском Android README; до bootstrap они не выполнялись. Форматирование/lint общие для workspace; после bootstrap закрепить точную применимую задачу в README.

Проверки безопасности и резервных копий: [SECURITY.md](../../../../docs/SECURITY.md), [TESTING.md](../../../../docs/TESTING.md). Реальные данные не использовать. Ошибки фиксировать в корневой docs/knowledge/ERRORS.md.
