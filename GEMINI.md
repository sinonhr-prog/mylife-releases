# Вход для Gemini

Перед работой явно прочитай [AGENTS.md](AGENTS.md) и [README.md](README.md). Они — общие правила проекта. Не считай этот файл заменой инструкций модулей.

Определи точный model ID по правилам [MODEL_ROUTING.md](harness/MODEL_ROUTING.md). Для подтверждённого `gemini-3.8-flash` прочитай [основной профиль](harness/profiles/GEMINI.md); для неизвестной модели не начинай реализацию.

Продолжение: [CURRENT.md](harness/CURRENT.md), [PROTOCOL.md](harness/PROTOCOL.md), текущая карточка из [PLAN.md](harness/PLAN.md), применимые [SKILL.md](harness/SKILLS.md). После каждого проверенного шага обновляй контекст и фиксируй ошибки. Закрытие этапа только при пройденных обязательных проверках.

Файл не содержит API-ключей, не переключает модель и не выдаёт разрешение на запуск разработки. Конкретный scope задаёт текущий запрос владельца.
