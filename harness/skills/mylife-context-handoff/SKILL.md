# Контекст без зависимости от чата

Использовать harness/CONTEXT.md и templates/handoff.md. Сохранять после каждого проверенного шага, а не только в финальном ответе.

- CURRENT: цель, run/model/phase/step, scope и источник разрешения, сделанные изменения, проверки со ссылками, блокеры, следующий конкретный шаг, файлы для чтения.
- Handoff: commit/digest, состояние незакоммиченного дерева, что нельзя потерять, гипотезы и результаты попыток, активный lock и способ безопасного продолжения.
- Ошибки — отдельные записи ERRORS, решения — ADR/decisions с фактическим sourceRef. Не копировать внутренние рассуждения или весь transcript.
- Перед передачей остановить запись, сохранить файл и освободить lock; следующий исполнитель сверяет файлы и заново подтверждает свою модель.
- После crash не удалять lock по возрасту. Проверить отсутствие прежнего процесса с оператором и записать восстановление.
- Приёмник продолжает незавершённый шаг, не переписывает проект с нуля и не считает старый PASS проверкой нового кода.

Не изменять глобальную память пользователя. Этот skill записывает только проектный контекст внутри текущего репозитория.
