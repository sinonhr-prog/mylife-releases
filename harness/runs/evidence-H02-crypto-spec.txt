## 2. Defined Cryptographic Architecture
- SQLCipher 4.6.1 for encrypted SQLite databases (`main.db` and `vault.db`) in WAL mode.
- RFC 9106 Argon2id via Bouncy Castle 1.78.1 (64 MiB memory, t = 3, p = 1, 32-byte output).
- Two-tier Key Envelope:
  - PIN path: Argon2id KDF key + Android Keystore device key.
  - Biometric path: Keystore biometric key with `CryptoObject` authorization.
- Archive format `.lifevault`:
  - Versioned header with Argon2id parameter bounds (max 128 MiB, max 10 iterations).
  - Tink Streaming AEAD (HKDF-SHA256 + AES-256-GCM, 4 KB chunks) for robust tamper and truncation detection.
- Safe PIN Change: atomic file replacement, memory zeroization via `Arrays.fill`.
- Scope separation: strict isolation of Main and Vault storage and encryption contexts.
