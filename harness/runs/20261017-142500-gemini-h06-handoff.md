## 1. Выполненные шаги

- **H06.1 — Перенести токены и компоненты**:
  - Токены стиля «Бумага / Фокус» в `core:designsystem`: `PaperBackground` (#FFFFFF), `PaperForeground` (#202020), `PaperSurface` (#F9F9F9), `PaperOutline` (#E0E0E0), `PaperFocusCardBackground` (#202020), `PaperFocusCardForeground` (#FFFFFF), `PaperFocusCardSubtext` (#D0D0D0), `PaperFocusCardLabel` (#AAAAAA), `PaperFocusCardButtonBorder` (#777777).
  - Компоненты в `local.mylife.core.designsystem.components`: `FocusCard` (выделенная графитовая карточка ближайшего дела), `SectionHeader` (заголовки разделов с опциональным действием «Все»), `FocusEmptyState` (спокойное пустое состояние без фейковых заглушек), `RatingBadge` (рейтинг от 1 до 10).
  - Тесты токенов и контрастности WCAG AAA (>15:1) в `ThemeTest.kt` (2/2 PASS).

- **H06.2 — Сделать drawer и shell**:
  - Реализован `MainDashboardShell` в `MainActivity.kt`: выдвижное меню слева по кнопке ☰ со всеми категориями (Главная, Покупки, Магазины, Парки, Кафе, Рестораны, Задачи, Заметки, Напоминания, Пароли (Сейф), Настройки).
  - Нижние вкладки (bottom navigation tabs) полностью отсутствуют.
  - Обработка системной кнопки Back: закрывает drawer, если он открыт; переходит на «Главную», если открыт другой раздел; выходит из приложения только с Главной.
  - Изоляция Сейфа: при переходе из раздела «Сейф» в любой другой пункт меню немедленно вызывается `sessionManager.lockVault()`.
  - Защита экрана `FLAG_SECURE` активна при вводе PIN и в Сейфе.

- **H06.3 — Реализовать покупки**:
  - Репозиторий и сессия Room: `StorageSession` в `:core:storage` инкапсулирует `AppDatabase` и DAO внутри модуля, выдавая наружу чистые интерфейсы репозиториев (`ProductRepository`, `TaskRepository`, `EncryptedAttachmentStore`).
  - Связи вложений для покупок: `ProductAttachmentCrossRef`, сохранение и загрузка зашифрованных фото покупок через Tink Streaming AEAD.
  - `PurchasesViewModel`: полный CRUD покупок, валидация (непустое название, рейтинг 1..10, неотрицательная цена), локальный поиск по тексту, фильтры (`ALL`, `ACTIVE`, `FAVORITE`, `ARCHIVED`), добавление и удаление зашифрованных фото.
  - `PurchasesScreen`: экран в утверждённом стиле «Бумага / Фокус», поиск, фильтрационные чипы, карточки покупок с рейтингом, диалоги создания/редактирования, подтверждение удаления.

- **H06.4 — Подключить доступную часть дашборда**:
  - `HomeViewModel` и `HomeScreen`: отображение даты, интро «Сначала главное / Остальное успеется», карточка Фокуса с ближайшим делом (или `FocusEmptyState`), секция актуальных задач и последних покупок.
  - Не реализованные пока разделы честно пусты (`FocusEmptyState`).
  - Unit-тесты `ProductFlowTest` (3/3 PASS): CRUD, поиск, архив/восстановление, рейтинг, проверка отсутствия сетевых запросов при сохранении URL.
  - Connected AndroidTest `MainActivityTest` (1/1 PASS): проверен на эмуляторе API 29 (Android 10), ввод 6-значного PIN, дашборд, открытие drawer по ☰, переход в покупки, возврат по Back.
