## 1. Выполненные шаги

- **H07.1 — Реализовать места**:
  - Категории мест в `DefaultCategories` («Магазины», «Парки», «Кафе», «Рестораны»), поддержка пользовательских категорий в `CategoryDao`, `PlaceDao`, `RoomCategoryRepository`, `RoomPlaceRepository`.
  - `PlacesViewModel`: CRUD мест, фильтрация по категории и статусу (Все / Хочу посетить / Посетил / Избранное), локальный поиск (по названию, адресу, описанию), валидация (название 1..160, рейтинг 1..10, lastVisitedAt не в будущем), безопасный перенос мест при удалении категории (`category-integrity`).
  - `PlacesScreen`: дизайн «Бумага», карточки мест, фильтры-чипы, диалоги добавления/редактирования, выбор фото и зашифрованное хранилище `EncryptedAttachmentStore`.
  - Интеграция в `MainActivity.kt`: drawer-навигация по категориям мест («Магазины», «Парки», «Кафе», «Рестораны»), действия в topBar (+) и кнопка «+ Добавить запись».
  - Тесты: `PlaceFlowTest` (5/5 PASS).

- **H07.2 — Реализовать заметки и задачи**:
  - `TasksViewModel` и `TasksScreen`: CRUD задач, смена статуса OPEN <-> DONE, строгая спецификационная сортировка (просроченные -> со сроком по возрастанию -> без срока -> приоритет HIGH/NORMAL/LOW -> createdAt -> id), фильтры (Текущие, Все, Выполненные, Важные), локальный поиск (заголовок, описание), безопасные черновики.
  - `NotesViewModel` и `NotesScreen`: CRUD заметок (заголовок 1..160, тело до 100 000), избранное, локальный поиск по заголовку и телу, фильтры (Все, Избранное), безопасные черновики.
  - Интеграция в `MainActivity.kt`: drawer-навигация («Задачи», «Заметки»), действия topBar (+), кнопка «+ Добавить запись».
  - Тесты: `TaskFlowTest` (5/5 PASS), `NoteFlowTest` (4/4 PASS).

- **H07.3 — Собрать DashboardRepository**:
  - `RoomDashboardRepository`: OPEN tasks по строгой спецификации (`overdue` -> `dueAsc` -> `nullDue` -> `priority` HIGH/NORMAL/LOW -> `createdAt` -> `id`).
  - `focusTask` — ближайшее дело в выделенной карточке.
  - `remainingTasks` — следующие до 2 дел без дублирования `focusTask`.
  - `recentVisits` — места с `lastVisitedAt <= now` по убыванию даты; места без посещений и даты в будущем исключены.
  - `recentRecords` — объединение неархивных покупок, мест, заметок и задач по `createdAt DESC`. Изоляция Сейфа и архива соблюдена.
  - `activeReminders` — активные напоминания по возрастанию времени сигнала.
  - `HomeScreen.kt` и `HomeViewModel.kt`: отображение всех живых разделов («Ближайшее дело», «Ещё в планах», «Напоминания», «Недавно посетил», «Последние записи») с возможностью быстрого перехода в соответствующую категорию.

- **H07.4 — Проверить связи и состояния**:
  - Тестирование удаления категорий с безопасным переносом мест в дефолтную категорию без потери данных.
  - Проверка стабильности `createdAt` при редактировании записей.
  - Проверка корректной работы пустых состояний (`FocusEmptyState`).
  - Проверка сохранения данных при перезапуске сессии / офлайн.
  - Тесты: `DashboardFlowTest` (7/7 PASS).
