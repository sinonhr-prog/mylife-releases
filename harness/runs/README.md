# Отчёты запусков

Пока запусков разработки нет. Здесь сохраняются `<runId>.json`, `<runId>-handoff.md` и санитизированные evidence-файлы/подкаталоги. Закрытый отчёт не переписывать; корректировка получает новый runId и объяснение. Ключи, личные базы, фотографии, полные секретные логи и credential-файлы сюда не помещать.

Шаблоны лежат в ../templates/. Их null/пустые поля специально не проходят gate: исполнитель заполняет их только наблюдаемыми результатами.
