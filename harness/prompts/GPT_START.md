# Запуск резервной GPT‑6.1 Sol с начала

Выбрать `gpt-6.1-sol` в среде, открыть проект и скопировать блок. Для приёма уже начатой работы вместо него использовать RESUME.md.

```text
В D:\Project\Моя жизнь выполни только H00 из harness/phases/H00.md.
Нужен проверяемый preflight готового плана Android-приложения,
без реализации APK. Дизайн утверждён: «Бумага / Фокус», меню слева.

Прочитай AGENTS.md, README.md, harness/MODEL_ROUTING.md.
Проверь фактическую модель по данным среды; ожидается gpt-6.1-sol.
Если модель неизвестна, запроси подтверждение и не изображай проверку.
Затем прочитай harness/profiles/GPT.md, harness/CURRENT.md, harness/PROTOCOL.md,
H00 и применимые проектные skills.

Доведи H00 до доказанного результата. Рутинные обратимые решения внутри
его scope принимай самостоятельно. Исследуй файлы/toolchain/devices,
проверь документационный пакет, сохрани ошибки, evidence и handoff.
Не устанавливай инструменты и не создавай Android-исходники.
Отделяй текущие факты от старых отчётов, планов и рекомендаций.

После gate H00 предложи конкретный диапазон H01–H02 и обязательные
недостающие решения. Не начинай реализацию до отдельного поручения.
Ответ: что готово, как проверено, что блокирует следующий этап.
```
