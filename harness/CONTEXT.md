# Карта контекста

## Минимальный пакет каждого старта

AGENTS.md → README.md → MODEL_ROUTING + один профиль → CURRENT.md + state.json → текущая phases/Hxx.md → scoped AGENTS/README затронутых модулей. Затем читать спецификации и skills, перечисленные карточкой. Не загружать все логи, все этапы и все skills в каждый запрос.

## Где искать

- Что строим: docs/PRODUCT.md; выбранный дизайн: design/DASHBOARD.md и design/dashboard.html?layout=focus (query применяется только при открытии браузера).
- Защита: docs/SECURITY.md; схемы/ключи уточняются ADR этапа H02, не выводятся из макета.
- Архитектура: docs/ARCHITECTURE.md; поля и dashboard sorting: docs/DATA_MODEL.md.
- Gates: docs/TESTING.md + карточка + BUILD.md. Команды до H01 плановые.
- Разрешённые действия: текущий человеческий prompt и authorizationRef; решения: decisions.json + docs/DECISIONS.md.
- Уже сделано: state.json, STATUS.md, закрытые run reports. Возможная незавершённая работа: CURRENT.md + фактический diff.
- Почему так: ADR, решения; что сломалось: ERRORS, relevant run evidence.

## Формат CURRENT.md

Максимум ориентировочно 120 строк: цель, выбранные решения, текущие model/runId/phase/step, разрешённый scope, фактические изменения, проверки с путями, блокеры, следующий точный шаг, перечень файлов для чтения. Не пересказывать всю историю и не сохранять внутренние рассуждения. Отделять факт, гипотезу и рекомендацию.

## Смена модели/чата

В handoff дать состояние дерева/commit если Git есть; иначе digest. Указать незакоммиченные изменения, что нельзя потерять, упавшие команды, проверенную гипотезу, следующий шаг, активную блокировку. Передающий агент освобождает lock после прекращения записи. Приёмник сверяет файлы и доверенные метаданные заново, не перезапускает проект с нуля. Полный чат не нужен для продолжения, если пакет актуален.

## При расхождении

Текущий запрос владельца и применимые инструкции имеют приоритет; runtime-факты определяются текущим кодом/проверками, а не STATUS. Если CURRENT и state расходятся, не дописывать предполагаемый успех: прочитать отчёт и восстановить последнее проверяемое состояние. Если изменён security-контракт, не продолжать по старому тестовому отчёту.
