# Какие skills использовать

Проектные skills созданы в harness/skills и не требуют сторонней установки. Их надо **прочитать по пути** в начале применимого шага. Это portable skill sources: автоматическое обнаружение из этого каталога не предполагается. Если среда поддерживает установку skills, можно отдельно зарегистрировать их через штатный механизм после проверки; текущий пакет не меняет глобальные настройки и защищённые каталоги агента.

| Skill | Когда обязателен | Путь |
|---|---|---|
| mylife-execute-slice | каждый запуск и шаг реализации | [SKILL.md](skills/mylife-execute-slice/SKILL.md) |
| mylife-verify-evidence | проверка шага, закрытие этапа и review | [SKILL.md](skills/mylife-verify-evidence/SKILL.md) |
| mylife-context-handoff | checkpoint, смена чата/модели, остановка | [SKILL.md](skills/mylife-context-handoff/SKILL.md) |
| mylife-android-security | ключи/PIN/хранилища/архив/фон/релиз | [SKILL.md](skills/mylife-android-security/SKILL.md) |
| mylife-compose-focus | интерфейс Compose, дашборд и меню | [SKILL.md](skills/mylife-compose-focus/SKILL.md) |

Базовые первые три применимы всем этапам, но их достаточно прочитать один раз за сеанс и перечитать после изменения. Security/UI читаются только в относящихся шагах. Skills не заменяют спецификации и не выдают право расширить scope.

## Дополнительные доступные навыки

В текущей среде Codex есть `project-structure-governance` (новый модуль/границы), `frontend-design` (существенное изменение макета), `openai-docs` (вопросы об OpenAI/Codex), `skill-creator` (изменение самих skills). В Gemini они **не считаются установленными**. Обязательные проектные процедуры полностью описаны локальными skills, поэтому отсутствие этих дополнительных навыков не блокирует реализацию. Не переносить абсолютные пути текущего компьютера в обязательный контракт другой среды.

Не устанавливать случайные наборы «Android/security expert» из интернета ради названия. Если нужен сторонний skill: сначала прочитать исходник, проверить команды/передачу данных/лицензию/область действия; только затем согласовать необходимую установку. Навыки Sites, imagegen, презентаций, таблиц и глобальной памяти для реализации этого приложения не требуются.

## Адаптеры среды

Проверка пакета `node scripts/verify-project.mjs` проверяет пять skills в ограниченном формате YAML: только name/description, имена, длину и незаполненные placeholders. Официальный quick_validate.py в текущем bundled Python не запускается из-за отсутствия PyYAML (ENV-003); это ограничение записано отдельно. Никакие глобальные зависимости для его обхода не устанавливались.

Gemini CLI использует GEMINI.md и поддерживает свои workspace/user skills; Codex использует AGENTS.md и собственную загрузку skills. В H00 проверить фактически загруженный контекст. В Antigravity или другой оболочке явно прикрепить AGENTS.md, профиль и нужные SKILL.md, если автоматического чтения нет. Не обещать поддержку конкретной команды CLI без проверки её установленной версии. Основной механизм пакета — обычные файлы и Node, независимые от оболочки.
