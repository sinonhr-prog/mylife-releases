# Бумага: дашборд и меню

Актуальное решение владельца от 16.10.2026: **«Бумага / Фокус»**, белый + графитовый; дашборд на главной; меню выезжает слева по ☰. [Открыть макеты](dashboard.html), выбрать «Фокус»; прямое открытие в браузере поддерживает параметр `?layout=focus`. Переключатель вариантов существует только для исследования. [Эталонный снимок](previews/paper-focus.png).

## Четыре компоновки

1. **Блоки**: полноширинные секции одна под другой. Крупные понятные строки, наименьшая плотность. Исторический вариант.
2. **Плитки**: задачи на всю ширину, напоминания и посещения в двух колонках, последние записи снизу. Больше информации видно одновременно.
3. **Фокус — утверждён**: ближайшее дело выделено графитовой карточкой, остальные блоки ниже. Реализовать именно эту компоновку.
4. **Лента дня**: спокойная вертикальная ось связывает дела, напоминания и недавние события. Нет дополнительных счётчиков и диаграмм.

Варианты показывают одинаковые синтетические данные. Это выбор одной компоновки для MVP; изменение порядка перетаскиванием и пользовательский конструктор не входят в текущий запрос.

## Общие правила

- Только #FFFFFF и #202020 как базовые цвета; серые линии/подписи — нейтральные оттенки. Без цветных акцентов.
- Системная типографика, заголовок 32 sp, разделы 15–16 sp, основной текст для будущего Android 16 sp. Макет сравнительный; плотность и шрифты Android проверяются отдельно.
- ☰ всегда слева сверху. Меню содержит все категории и настройки; доступно прокручивание, выбранный пункт выделен. Пользовательские категории появятся здесь после реализации.
- Движение слева, затемнение фона, закрытие крестиком/снаружи/Escape, удержание и восстановление фокуса. При reduced motion движение отключается. В Android вместо Escape используется Back.
- Нижних вкладок нет; кнопка добавления закреплена отдельно внизу. Длинные блоки прокручиваются выше неё.
- Отметка посещения ручная; никаких предположений на основе геолокации/редактирования карточки. Сейф исключён из всех блоков.
- Меню и переходы работают в демонстрации. Сохранение/поиск/разблокировка обозначены как сценарии, без реальных данных.

## Оценка

«Блоки» проще для чтения и крупного шрифта. «Плитки» удобнее для быстрого обзора, но узкие колонки требуют проверки в Compose. «Фокус» сильнее выделяет приоритет. «Лента» визуально легче, но требует больше прокрутки. Полные требования и сортировки записаны в PRODUCT.md/DATA_MODEL.md проекта.
