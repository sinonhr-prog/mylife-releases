## Концепция

Один личный каталог, а не панель показателей. Главная отвечает «что сегодня и что под рукой». Фирменный приём — крупная спокойная надпись «Моё» и короткие человеческие названия разделов. Сейф отделён и визуально, и в сценарии входа.

Верх: название/контекст → поиск → содержимое → одна основная кнопка. Низ: Главная / Каталог / Дела / Сейф. Категории магазинов, парков и кафе внутри каталога, поэтому нижняя навигация не перегружена.

```text
┌─────────────────────┐
│ 9:41       локально │
│ Моё                 │
│ Всё важное рядом    │
│ Поиск по записям     │
│ Сегодня             │
│ □ Забрать заказ     │
│ Категории           │
│ Покупки · Места      │
│ Заметки · Напоминания│
│ Добавить запись     │
│ Главная Каталог Дела │
└─────────────────────┘
```

Типографика Android: системный Roboto, 32 sp заголовок / 22 sp раздел / 16 sp основной / 13–14 sp подписи; крупные заголовки с небольшим отрицательным tracking. Макет использует локальные Segoe UI/Arial без скачивания. Минимум областей нажатия 48 dp, шаг отступов 4/8, контент 20–24 dp, радиус 12–20 dp, без градиентов и декоративных теней. Оценка обязательно текстом «9 / 10», состояние не передаётся одним цветом.

Экраны в каждой теме: главная, покупки, карточка товара, места, дела, заметки, закрытый сейф. Выбор темы меняет только визуальные токены; сценарии одинаковые для честного сравнения. Сохранение, ввод PIN и реальные операции отсутствуют; демонстрационные кнопки показывают подсказку. В будущем Compose нужны все empty/loading/error/locked состояния из TESTING.md.

## Самопроверка дизайна

Пять тем не превращены в пять разных приложений. Не добавлены метрики расходов, карты, онлайн-статусы или обещания защиты, которых нет в требованиях. Акцент используется для действий и выбора. Визуальный минимум не убирает подписи и доступность. Реальные фото, шрифты 200% и TalkBack проверяются на Android отдельно.
